# Palmo Coconut Co.

Next.js (App Router) marketing site for Palmo — cold-pressed coconut water.

## Stack

- Next.js 16 + React 19
- JavaScript / JSX (no TypeScript)
- Tailwind CSS 4

## Scripts

```bash
npm run dev
npm run build
npm start
```

## Routes

- `/` — home
- `/flavours` — all flavours + pack picker / basket
- `/story` — brand story
